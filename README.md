# OnionHop Bridges Collector

Automatically collects, validates and archives Tor bridges for the
[OnionHop](https://github.com/center2055/OnionHop) app. A GitHub Action runs
hourly to fetch fresh bridges from the official Tor Project and community
sources, then TCP/TLS-tests them and publishes the results under `bridge/`.

> This README is regenerated by `main.py` on each run with live counts.

## Lists (per transport: obfs4, webtunnel, vanilla)

For each transport and IP version there are three lists:

- `*_tested.txt` — passed a TCP/TLS reachability test on the last run (recommended)
- `*_72h.txt` — first seen in the last 72 hours
- `*.txt` — full archive (union over time)

IPv6 variants add `_ipv6` (e.g. `obfs4_ipv6_tested.txt`).

## Consuming

Fetch the raw files directly, e.g.
`https://raw.githubusercontent.com/center2055/OnionHop-Bridges-Collector/main/bridge/obfs4_tested.txt`.
For censorship resilience, also mirror these paths behind GitHub Pages, a CDN
and/or a self-hosted domain and try them in order.

## Sources

- Official Tor BridgeDB (`https://bridges.torproject.org`)
- Community seed: [Delta-Kronecker/Tor-Bridges-Collector](https://github.com/Delta-Kronecker/Tor-Bridges-Collector)

## Run locally

```bash
pip install -r requirements.txt
python main.py
```
